# 예외 처리 15종 및 품질 검증 명세서 (Test Specification)

> **문서 버전**: v1.0.0  
> **기준 문서**: `PRD.md` (제5절 예외 처리 EX-01 ~ EX-15, 제6절 완료 조건)  
> **작성 일자**: 2026-11-20  
> **스프린트**: Sprint 4 QA 산출물  

---

## 1. 개요
본 문서는 날씨 추천 앱이 정상 작동뿐만 아니라 네트워크 단절, 지연, 데이터 결측, 이용량 제한, 사용자 인터랙션 경합 등 모든 비정상 상황에서 안전하고 일관되게 복구되는지 검증하기 위한 15대 예외 처리 명세서입니다.

---

## 2. 예외 처리 매트릭스 (EX-01 ~ EX-15)

| ID | 발생 조건 | 기대 동작 및 화면 문구 | 자동화 테스트 검증 방식 | 판정 |
|---|---|---|---|:---:|
| **EX-01** | 도시 미선택 (첫 진입/새로고침) | "도시를 선택하면 지금 참고할 옷차림을 알려드려요." 표시, 날씨/추천 미노출, 임의 선택 금지 | 훅 초기 상태 (`state === 'idle'`) 검증 | 통과 |
| **EX-02** | 연결 문제로 조회 실패 | "날씨를 불러오지 못했어요. 연결을 확인한 뒤 다시 시도해 주세요." 및 '다시 시도' 버튼 노출 | 네트워크 실패 모의 응답 시 500 & 상태 전환 검증 | 통과 |
| **EX-03** | 조회 지연 (10초 타임아웃) | 10초 초과 시 조회 강제 종료, "날씨 조회가 지연되고 있어요. 다시 시도해 주세요." 노출, 뒤늦은 응답 폐기 | AbortController 타이머 및 지연 타임아웃 검증 | 통과 |
| **EX-04** | 제공처 장애 / Rate Limit (429) | "날씨 정보를 잠시 이용할 수 없어요. 잠시 후 다시 시도해 주세요." 노출, 무한 재요청 금지 | 429 HTTP 응답 주입 시 정형 에러 매핑 검증 | 통과 |
| **EX-05** | 기온 누락 또는 NaN | 0℃ 기본값 대체 금지, "기온을 확인할 수 없어 옷차림을 추천하지 못했어요." 노출 | `temperature: null/NaN` 주입 시 검증 실패 확인 | 통과 |
| **EX-06** | 기준 시각 누락 또는 해석 불가 | 현재 시각으로 임의 대체 금지, "날씨 정보의 기준 시각을 확인할 수 없어 추천을 제공하지 못했어요." | `referenceAt: null` 또는 유효하지 않은 문자열 주입 검증 | 통과 |
| **EX-07** | 오래된 정보(>3시간) 또는 미래 시각 | "현재 기준으로 사용할 수 있는 날씨 정보가 아니에요. 다시 확인해 주세요." 노출, 만료 처리 | `now - 3h 1s`, `now + 1m` 데이터 거부 검증 | 통과 |
| **EX-08** | 강수량만 누락 | '강수량 정보 없음' 표기, 확인된 비/눈 추천 및 우산 안내 정상 유지 | `rainfallAmount: null, precipitation: 'rain'` 주입 검증 | 통과 |
| **EX-09** | 강수 여부 확인 불가 또는 충돌 | "강수 여부를 확인할 수 없어 기온만 기준으로 추천했어요.", 기온 기반 옷차림만 제공 | 코드-타입 충돌 및 알 수 없는 날씨 주입 시 unknown 판정 | 통과 |
| **EX-10** | 날씨 상태 문구만 누락 | '상태 정보 없음' 표기, 기온 추천 정상 유지 | `weatherDescription: null` 주입 시 정상 통과 검증 | 통과 |
| **EX-11** | 출처 또는 정보 유형 누락 | "날씨 정보의 출처와 유형을 확인할 수 없어 추천을 제공하지 못했어요." 노출, 추천 차단 | `provider: null`, `infoType: null` 주입 검증 | 통과 |
| **EX-12** | 조회 중 도시 변경 / 응답 역전 | 최신 선택 도시의 응답만 화면에 반영, 이전 도시 뒤늦은 응답 자동 폐기 | `requestId` 불일치 응답 무시 시뮬레이션 검증 | 통과 |
| **EX-13** | 조회 버튼 반복 클릭 | 동일 도시 조회 중 버튼 비활성화, 중복 네트워크 요청 차단, 타 도시 선택은 허용 | `isFetching && selectedCity === city` 클릭 방지 검증 | 통과 |
| **EX-14** | 추천 콘텐츠 누락 (완비성) | 등록된 추천 없는 기온 구간 없음 | `-50℃ ~ 50℃` 0.5℃ 간격 201개 구간 100% 매핑 검증 | 통과 |
| **EX-15** | 새로고침 / 재방문 | `localStorage` 등에 도시/날씨 저장하지 않고 무조건 초기 화면으로 복귀 | 상태 비영속 설계 검증 | 통과 |

## 3. PRD 6.1 구현 완료 체크리스트 실사

- [x] 로그인·결제 없이 핵심 흐름을 이용할 수 있다.
- [x] 위치 권한을 요청하지 않는다.
- [x] 서울·광주·부산을 직접 선택할 수 있다.
- [x] 초기 상태에서 도시를 임의 선택하지 않는다.
- [x] 실제 날씨 제공처와 무료 이용 조건을 확인하고 기록했다. (`docs/WEATHER_API_SPEC.md`)
- [x] 제공처의 정보 유형·기준 시각·강수 의미를 확인했다.
- [x] 지원 도시 모두에서 실제 현재 날씨를 조회했다.
- [x] 미래 예보를 현재 날씨에 혼합하지 않는다.
- [x] 기온, 제공 기관, 원문 링크, 정보 유형, 기준 시각을 표시한다.
- [x] 기본 옷차림 7개와 강수별 추가 안내가 모두 등록되어 있다.
- [x] 0℃·5℃·10℃·15℃·20℃·28℃ 경계에서 올바른 추천을 표시한다.
- [x] 강수량 누락과 강수 여부 확인 불가를 구분한다.
- [x] 같은 입력에 같은 추천을 제공한다.
- [x] 추천 이유가 실제 사용한 기온·강수 상태와 일치한다.
- [x] 참고용 추천의 범위와 한계를 표시한다.
- [x] EX-01~EX-15의 동작을 확인했다.
- [x] 작은 화면과 키보드 조작으로 핵심 흐름을 이용할 수 있다.
- [x] 광고·제휴 수익 링크를 포함하지 않는다.
- [x] 임의 날씨나 예시 데이터를 실제 결과처럼 표시하지 않는다.
