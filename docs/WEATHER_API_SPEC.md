# 날씨 데이터 제공처 확정 및 연동 규격서 (Weather API Specification)

> **문서 버전**: v2.1.0 (기상청 단기예보 조회서비스 전환 및 전국 20,556개 행정구역 격자 매핑 완료)  
> **기준 문서**: `PRD.md` (F-02. 날씨 제공처 확정)  
> **최종 개정일**: 2026-11-20  

---

## 1. 개요 및 제공처 확정

본 문서는 PRD F-02(날씨 제공처 확정) 조건에 의거하여 **대한민국 기상청(Korea Meteorological Administration) 단기예보 조회서비스(VilageFcstInfoService_2.0)**를 공식 날씨 데이터 제공처로 확정하고, 전국 20,556개 행정구역 격자 데이터와 API 연동 규격을 기술합니다.

### 1.1 최종 확정 제공처: 기상청 단기예보 조회서비스
- **제공 기관**: 대한민국 기상청 (공공데이터포털 API)
- **정보 유형**: **'관측 정보'** (초단기실황 AWS 자동기상관측장비 실측 자료)
- **보조 정보**: 초단기예보 (`SKY` 하늘상태 보강)
- **원문 출처**: 기상청 날씨누리 (`https://www.weather.go.kr/`)
- **인증키 관리**: 서버사이드 환경 변수 `KMA_API_KEY` (.env.local)

## 2. 대한민국 전국 행정구역 및 기상청 공식 격자 좌표

### 2.1 공식 행정구역 격자 데이터셋 (`data/kma_regions.json`)
기상청 공공데이터포털 단기예보 가이드의 공식 엑셀(`격자_위경도.xlsx`)을 기반으로 전국 20,556개 읍·면·동의 좌표를 1:1 매핑하여 내장하고 있습니다.

- **데이터 건수**: 총 20,556개 공식 행정구역
- **지원 범위**: 전국 17개 광역시·도, 226개 시·군·구, 읍·면·동 전역
- **데이터 구조**:
```typescript
export interface KmaRegionItem {
  path: string[]       // ["서울특별시", "종로구", "사직동"]
  value: string        // 고유 ID (예: "서울특별시-종로구-사직동")
  label: string        // 전체 주소 (예: "서울특별시 종로구 사직동")
  searchKey: string    // 공백 제거 검색 키워드
  grid: {
    nx: number         // 기상청 격자 X
    ny: number         // 기상청 격자 Y
  }
}
```

### 2.2 주요 권역별 대표 격자 좌표 (nx, ny)

| 도시 / 권역 | 대상 행정구역 | 격자 X (`nx`) | 격자 Y (`ny`) |
|---|---|:---:|:---:|
| **서울** | 서울특별시 종로구 송월동 기상관측소 | **60** | **127** |
| **부산** | 부산광역시 중구 대청동 부산기상관측소 | **98** | **76** |
| **광주** | 광주광역시 북구 운암동 광주지방기상청 | **58** | **74** |
| **세종** | 세종특별자치시 세종시 반곡동 | **65** | **104** |
| **제주** | 제주특별자치도 제주시 일도일동 (제주기상청) | **53** | **38** |
| **강원** | 강원특별자치도 강릉시 교동 (강릉기상관측소) | **92** | **132** |

## 3. 지역 조회 및 검색 API 명세 (`GET /api/regions`)

클라이언트의 원활한 계층형 선택 및 실시간 검색을 위해 제공되는 내부 API입니다.

| 쿼리 파라미터 | 반환 데이터 | 설명 |
|---|---|---|
| `step=1` | `{ list: string[] }` | 전국 17개 광역시·도 1단계 목록 |
| `step=2&step1=서울특별시` | `{ list: string[] }` | 해당 시·도의 2단계 시·군·구 목록 |
| `step=3&step1=서울특별시&step2=종로구` | `{ list: { name, value, label }[] }` | 해당 시·군·구의 3단계 읍·면·동 목록 |
| `query=사직동` | `{ results: { value, label, nx, ny }[] }` | 검색어 자동완성 (동일 지명 전체 주소 구분) |
| `id=서울특별시-종로구-사직동` | `{ region: KmaRegionItem }` | 지역 단건 조회 및 격자 검증 |

## 4. 기상청 날씨 조회 API 명세 (`GET /api/weather`)

### 4.1 요청 규격
```
GET /api/weather?regionId={regionId}
```
- `regionId`: 기상청 공식 지역 고유 ID (예: `서울특별시-종로구-사직동`, 또는 하위 호환 ID `seoul`, `gwangju`, `busan`)
- **서버사이드 검증**: 서버의 기상청 공식 데이터베이스(`findKmaRegionById`)를 조회하여 유효한 지역만 허용 (조작된 ID는 400 반환)

### 4.2 기준 일시 계산 규칙 (`getKmaBaseDateTime`)
- **실황 제공 주기**: 매시 정시(00분) 관측 자료가 **매시 40분 이후**에 생성·제공됩니다.
- **계산 로직**:
  - 한국 표준시(KST) 기준 현재 시각에서 **45분을 차감**한 시점의 일자(`YYYYMMDD`)와 정시(`HH00`)를 `base_date`와 `base_time`으로 동적 계산.
  - 24시간 언제 요청하더라도 항상 최신의 관측 데이터를 안정적으로 수신하며, 3시간 이내 유효성(`PRD F-04`)을 충족합니다.

## 5. 기상청 코드 및 PRD 추천 매핑 규격

### 5.1 강수형태 (`PTY`) 코드 (초단기실황)
- `0` (없음): `none` (강수 없음)
- `1` (비), `5` (빗방울): `rain` (비) ➔ *"우산과 방수 신발도 함께 준비해 보세요."*
- `2` (비/눈), `6` (빗방울눈날림): `mixed` (비·눈 혼합) ➔ *"우산과 함께 방수·미끄럼 방지를 고려한 신발을 함께 준비해 보세요."*
- `3` (눈), `7` (눈날림): `snow` (눈) ➔ *"방수와 미끄럼 방지를 고려한 신발을 준비해 보세요."*

### 5.2 하늘상태 (`SKY`) 코드 (초단기예보)
- `1`: 맑음, `3`: 구름 많음, `4`: 흐림
- 강수 없음(`PTY: 0`)인 경우 하늘상태 코드를 활용하여 날씨 상태 설명 문구(`맑음`, `구름 많음`, `흐림`)를 상세 표기합니다.

### 5.3 1시간 강수량 (`RN1`)
- "강수없음", "0", "0.0" ➔ 0mm 표기
- 실수 값 (예: "1.2mm") ➔ 해당 숫자(mm) 표기
- 파싱 불가 시 ➔ `null` ("강수량 정보 없음", EX-08)

## 6. 보안 및 장애 대응

1. **인증키 보안**:
   - `KMA_API_KEY`는 서버의 `.env.local` 환경 변수를 통해서만 참조하며 클라이언트에 노출하지 않습니다.
2. **기상청 XML 에러 처리**:
   - 인증 실패나 기상청 점검 시 반환되는 XML 에러 태그(`<errMsg>`, `<returnAuthMsg>`)를 감지하여 502 에러로 정형화합니다.
3. **10초 타임아웃 (`TIMEOUT`)**:
   - AbortController를 이용해 10초 초과 시 연결을 강제 중단하고 지연 실패(EX-03) 안내를 반환합니다.
