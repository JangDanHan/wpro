> **작성 일자**: 2026-11-20

## 1. 개요 및 제공처 확정

본 문서는 PRD F-02(날씨 제공처 확정) 조건에 의거하여 **기상청(Korea Meteorological Administration) 단기예보 조회서비스(VilageFcstInfoService_2.0)**를 공식 날씨 데이터 제공처로 확정하고 연동 규격을 기술합니다.

### 1.1 최종 확정 제공처: 기상청 단기예보 조회서비스
- **제공 기관**: 대한민국 기상청 (공공데이터포털 API)
- **정보 유형**: **'관측 정보'** (초단기실황 AWS 자동기상관측장비 실측 자료)
- **보조 정보**: 초단기예보 (`SKY` 하늘상태 보강)
- **원문 출처**: 기상청 날씨누리 (`https://www.weather.go.kr/`)

## 3. 기상청 API 호출 및 시각 계산 규칙

### 3.1 엔드포인트
- **초단기실황 조회**: `https://apis.data.go.kr/1360000/VilageFcstInfoService_2.0/getUltraSrtNcst`
- **초단기예보 조회**: `https://apis.data.go.kr/1360000/VilageFcstInfoService_2.0/getUltraSrtFcst`

### 3.2 제공 시각 및 기준 시각 계산 (`getKmaBaseDateTime`)
- **실황 제공 주기**: 매시간 정시(00분) 관측 자료가 **매시간 40분 이후**에 생성·제공됩니다.
- **계산 로직**:
  - 한국 표준시(KST) 기준 현재 시각에서 **45분을 차감**한 시점의 일자(`YYYYMMDD`)와 정시(`HH00`)를 `base_date`와 `base_time`으로 사용합니다.
  - 이를 통해 24시간 언제 요청하더라도 `NO_DATA` 에러 없이 항상 가장 최신의 관측 데이터를 안정적으로 수신합니다.
  - 기준 시각은 `YYYY-MM-DDTHH:00:00+09:00` 타임스탬프로 환산되며, PRD F-04의 **"3시간 이내 유효"** 기준을 100% 충족합니다.

## 4. 기상청 기상 코드와 PRD 매핑 규칙

### 4.1 강수형태 (`PTY`) 코드
- `0` (없음): `none` (강수 없음)
- `1` (비), `5` (빗방울): `rain` (비) ➔ *"우산과 방수 신발도 함께 준비해 보세요."*
- `2` (비/눈), `6` (빗방울눈날림): `mixed` (비·눈 혼합) ➔ *"우산과 함께 방수·미끄럼 방지를 고려한 신발을 함께 준비해 보세요."*
- `3` (눈), `7` (눈날림): `snow` (눈) ➔ *"방수와 미끄럼 방지를 고려한 신발을 준비해 보세요."*

### 4.2 하늘상태 (`SKY`) 코드 (초단기예보 연동)
- `1`: 맑음
- `3`: 구름 많음
- `4`: 흐림
- 강수 없음(`PTY: 0`)인 경우 하늘상태 코드를 사용하여 날씨 상태 문구(`맑음`, `구름 많음`, `흐림`)를 상세 표시합니다.

### 4.3 1시간 강수량 (`RN1`)
- "강수없음" 또는 "0", "0.0" ➔ 0mm 표기
- 실수 값 (예: "1.2mm") ➔ 해당 숫자(mm) 표기
- 파싱 불가 시 ➔ `null` ("강수량 정보 없음", EX-08)

## 5. 보안 및 예외 처리

1. **인증키 보안**:
   - `KMA_API_KEY`는 서버의 `.env.local` 환경 변수를 통해서만 참조하며, 브라우저 클라이언트에 절대 노출하지 않습니다.
2. **인증키 누락 대응 (`AUTH_KEY_MISSING`)**:
   - 환경 변수 미설정 시 안전한 정형 500 에러 반환.
3. **기상청 XML 에러 처리**:
   - 인증 실패나 장애 시 반환되는 XML 에러 태그(`<errMsg>`, `<returnAuthMsg>`)를 감지하여 502 에러로 정형화.
4. **10초 타임아웃 (`TIMEOUT`)**:
   - AbortController를 이용해 10초 초과 시 연결 강제 중단 및 지연 실패(EX-03) 안내.
